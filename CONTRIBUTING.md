## 🛠️ Contribution Guidelines

1. **Open an Issue First:** For major features or architectural changes, please open an issue first to discuss the design and scope.
2. **Code Standards:** Python code should adhere to PEP 8 standards where applicable.
3. **Hardware Verification:** When modifying input capture, ADB streaming, or gamepad emulation logic, verify changes on physical hardware (e.g. testing with actual DualShock 4, DualSense, or Xbox gamepads connected via Android).
4. **PR Checklist:** Complete the Contributor License Agreement confirmation in your pull request description using the provided PR template.
